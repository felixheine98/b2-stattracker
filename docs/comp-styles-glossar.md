# Glossar: Comp-Styles

Begriffe der Kategorisierung nach Style, siehe [Entscheidung](adr/002-comp-styles.md).

| Begriff | Bedeutung |
| --- | --- |
| Comp | Ein Turnier im Stattracker (`Tournament`), etwa „EMC S8“ oder „TFH 24h #5“. |
| Style | Der Fahrstil, der eine Comp als Ganzes prägt. Jede Comp hat genau einen, ohne Ausnahme; er hängt an der Comp, nicht an der einzelnen Map. |
| Style-Liste | Die festen Styles im Code: Tech, Fullspeed, Dirt, Ice, RPG, Endurance, Mixed. |
| Mixed | Style einer Comp, deren Mappool keinen Schwerpunkt hat. Ein eigener Style, keine Aufzählung mehrerer. |
| Endurance | Style aller Langstreckenrennen. Alle TFH-Rennen tragen ihn, auch die 12h-RPG-Ausgaben. |
| RPG | Style für RPG-Comps außerhalb von TFH. Die 12h-RPG-Rennen gehören nicht dazu. |
| By style | Block im Spielerprofil mit einer Zeile pro Style und den Kennzahlen der Format-Zeilen. |
